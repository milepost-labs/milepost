Milepost

A milepost marks how far along the road you have come.

Conditional disbursement infrastructure on Stellar. Start with the architecture overview in the README.

Crates

milepost_program
One funding round: contributions, applications, review, awards, tranche release, refunds.
milepost_registry
Factory and protocol configuration. Deploys programmes and holds treasury, fee, and authorisation.
milepost_attest
Schema-based attestation registry. Independently useful outside the protocol.
milepost_record
Portable, non-transferable recipient standing.
milepost_policy_spend
Smart wallet policy signer limiting spend to verified payees.
milepost_types
Shared types crossing contract boundaries.
